    How this ranks

    The same function scores every protocol, from the snapshot's own figures only. No name is special-cased and no row is hand-picked.

    • Base is a power law, not a multiple. Token value grows slower than TVL: a protocol with 500× the TVL of another is not worth 500× as much, because each extra dollar of locked value buys less attention and less room to grow. A $1B-TVL protocol bases at $100M; value rises as TVL to the ¾ power.
    • Growth is asymmetric. A week of inflows is weak evidence, so upside earns 0.40 per point; a week of outflows is a warning, so downside costs 0.80 per point. Clamped to −80% / +200%.
    • Maturity is logarithmic. A protocol that has run for years with no token has survived audits, cycles and competition without issuing one. The first year matters most; the factor saturates at 1.20 after four years. Unknown age counts as one year.
    • Breadth is a nudge. Each chain up to six adds 2%: multi-chain reach is real distribution, but a protocol on 45 chains is not 45× the one on a single chain.

    Age is the time since the protocol was first listed, the best record of how long it has run with no token. “Records no token” is what the snapshot says, never a claim that it has none. Implied value is a model, not a price and not a prediction of whether or when a token is issued.
